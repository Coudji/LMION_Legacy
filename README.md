# Let Me In... Or Not (LMION)

Project Zomboid Build 42 mod project focused on movable openings and access systems.

## Modules

- `LMION_Core` — shared framework and developer/debug tooling.
- `LMION_Build` — construction, crafting and placement of opening families.
- `LMION_Pickup` — pickup and replacement of passable opening systems such as doors, gates, sliding doors and garage doors.

Future optional modules may add locksmithing and access-control systems.

> Status: active development.
